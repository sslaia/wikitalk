WikiTalk

Discussions & Collaboration for Wikimedia Projects at Your Fingertips

WikiTalk is a modern Flutter-based mobile application designed for Wikimedia volunteers and contributors to read, monitor, and participate in talk page discussions across Wikipedia, Wiktionary, and other sister projects.

Key WikiTalk Features

A seamless, fast discussion experience connected directly to the Wikimedia ecosystem.

💬

WhatsApp-Style Quoted Replies

Replying to messages displays the author alongside the first line snippet of the message quoted, making long discussion threads clear and effortless to navigate.

New in this Release
🌐

Multi-Project & Multi-Language

Explore discussions across diverse Wikimedia language editions (English, Indonesian, Javanese, Sundanese, Nias, etc.) for both Wikipedia and Wiktionary.

MediaWiki DiscussionTools
📌

Custom Channels

Monitor any talk page easily. Add specific user talk pages, community portals, or dedicated project pages as custom channels with unread badges.

Flexible Channels
⚡

Full Offline Support

Discussions are cached in a local SQLite database. Read past discussions and prepare drafts even without an active internet connection.

SQLite Offline Cache
🔐

Secure Wikimedia OAuth2 Login

Log in securely using official Wikimedia OAuth2 authentication without sharing passwords. Anonymous users can browse public discussions freely.

Secure & Verified
🎨

Codex Theme & Adaptive Layout

Clean interface inspired by Wikimedia Codex Design System. Supports System, Light, and Dark modes, plus multi-pane responsive layout for tablets.

Codex Theme & Tablet Ready
